# 千世书 · thousand-lives

> AI 文字人生模拟器：一回合一次抉择，走到属于你的结局，免 Key 即玩

点开一个剧本，你就是那个人——宗门里没有靠山的散修、上海孤岛上的潜伏者、废土上刚捡回一条命的幸存者。每回合读一段剧情、落一次子，属性悄悄改写你能看到的下一段故事，直到某一回合书页停在只属于你的结局。

## 开局要什么

| 事项 | 说明 |
|------|------|
| 安装 | 不用。纯前端，打开网页就是全部 |
| API Key | 本地试玩不用——每个剧本自带手写事件池，能整局玩完；AI 驱动才要 |
| 一局多长 | 四十来回合，可随时存档，下次从命书阁接着玩 |
| 存档 | 只在这台浏览器（`localStorage`），清缓存或换设备就会丢 |
| 语言 | 只有中文，简体 / 繁体可切 |

## 玩法亮点

- **数字即故事**：属性按数值落入命名状态（理智「清醒 / 动摇 / 濒临崩溃」），作为硬指令注入 AI——理智崩了就必然出现幻觉
- **落子之后才揭晓**：选项不预告加减；掷骰与命运无常本就会改写它，下一段卷文里才报出真正的增减
- **没有被灰掉的选项**：状态再差也只是「勉力一试」；选项之外还能自己写一个行动，交给 AI 裁定
- **视觉小说式呈现**：整屏场景插画为幕，卷文浮层承载剧情，走过的回合汇成一卷命运长卷
- **结局卡 / 命运卡**：S～D 评级、专属称号、高光配图与挑战链接，一键分享到微博 / QQ 空间 / X / Telegram
- **61 枚成就 + 结局图鉴**：累计记录见过的结局，把「再开一局」变成收集

## 怎么玩

1. 打开 **[lives.newzone.top](https://lives.newzone.top)**，挑一个剧本
2. 选**本地试玩**或 **AI 驱动**，再选一个开局身份——身份真的决定你会遇到哪条剧情线
3. 每回合读剧情、点一个选项，或「自己写一个行动」；属性到某个组合、或回合耗尽即触发结局

想换成自己的大模型：右上角 ☰ → 设置 → 选服务商（内置 24 家预设，自动填好 Base URL 与推荐模型）→ 填 Key。

> [!TIP]
> API Key 只写进这台浏览器的 `localStorage`，绝大多数服务商的请求从你的浏览器直发。少数不发 CORS 头的（设置里标着「必须开」）要经一台中转，你的 Key 与整段 prompt 会经过它——纯透传、无日志、只转发白名单内的域名，也可以换成自建的。详见 [配置 AI](docs/ai-providers.md#cors-中转)。

## 已知限制

- **本地试玩的剧情来自手写事件池**，同一剧本连玩几局会撞到重复片段；要每局都不一样得填 Key 走 AI 驱动
- **AI 驱动按你自己的 Key 计费**：每回合都要向模型请求一次，先用本地试玩看看合不合胃口
